# 50-state coverage matrix — Phase 2 research

> Purpose: the research layer for the Phase 2 decision on what to expand into.
> Written **before** new state pages exist, per `docs/expansion-roadmap.md` §2.
> A state not in the "selected" table is not a rejection of the state — it is a
> record that its bar was not cleared *this session*, with the specific gap named.

**Session date: 2026-09-28. Method: web search to identify the official
administrator, then direct reads of official pages. A state is buildable only
when (a) the administrator is identifiable from a primary source that was
actually read, (b) the appeal/deadline rules are readable from official pages,
and (c) the owner-facing entry points (property search, notices) are verifiable.**

**Fase 4 update (same date): four states — Ohio, North Carolina,
Massachusetts and Virginia — cleared the full publication gate and were
published as hub-only pages. The gate table and the honest gaps are in
`docs/expansion-roadmap.md` §7. The matrix below is the Phase 2/3 record and
is kept for the trail.**

## 3. What was selected and why

1. **Dallas County, Texas (published, Phase 2).** The county gate's last criterion — a
   verifiable property-search URL — was closed with a live browser read of
   DCAD's Search Appraisals pages. Full trail in `docs/dallas-county-research.md`.
2. **Colorado (published, Phase 3).** The Phase-2 verdict ("buildable, not yet
   published") was re-run through the full gate rather than trusted: the
   real-property vs personal-property tracks were separated (the earlier read
   had conflated them), the June 8 deadline was confirmed on two independent
   DPT pages, and a county-based property search was verified live (Denver) —
   with the state's own assessor directory used as the official index instead
   of hand-maintaining 64 county URLs.
